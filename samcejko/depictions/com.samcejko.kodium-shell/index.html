Kodium Shell

Shells for Kodium's terminal

iOS lets no app of the App Store kind start processes, Kodium neither. This small daemon, started by launchd for each connection on 127.0.0.1:47070 only, runs a login shell (bash) on a pseudo terminal as the user mobile for Kodium's terminal panel. It answers only Kodium: a connection has to present the token Kodium keeps in its container.

Features

  • Provides the local shell connection used by Kodium's terminal panel.
  • Runs bash as the mobile user on a pseudo terminal.
  • Starts on demand through launchd.
  • Listens only on the device's loopback address, 127.0.0.1:47070.
  • Accepts authenticated connections carrying Kodium's token.

Good to know

  • Install together with Kodium; without it the terminal panel has no shell
