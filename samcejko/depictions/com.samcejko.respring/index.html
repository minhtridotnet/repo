Respring

Instant SpringBoard restart utility from home screen or terminal

Respring provides a fast, clean way to restart SpringBoard on jailbroken iOS devices without rebooting the entire operating system. Tap the home screen icon or run the command-line tool after installing tweaks, changing themes, or refreshing icon caches.

Features

  • One-tap SpringBoard restart directly from the home screen.
  • Includes command-line utility for SSH and terminal sessions.
  • Cleanly flushes SpringBoard state without a full kernel reboot.
  • Supports legacy 32-bit devices (iOS 5–10) and modern rootless 64-bit jailbreaks (iOS 15+).

Good to know

  • Tested on iOS 6.1.3 (ARMv7) and rootless iOS 16 (ARM64).

What's new in 1.0.1

  • 1.0.1: Correct the system library dependency that could prevent launch on iOS 5.
  • 1.0.0: Initial release.
