Kodium

Editor kódu: workbench VS Code na iPadu 2

A code editor for jailbroken iOS 6: the VS Code workbench Kodium puts the workbench of the open-source VS Code, assembled through monaco-vscode-api, on iOS 6 devices: files, editor tabs, syntax highlighting, search, the command palette, settings and keybindings. It runs on the device itself, on the engine of the Surfari browser: its own TLS 1.2 connections, and modern CSS and JavaScript rewritten for the iOS 6 WebKit. Made for iOS 6.x on armv7 devices such as the iPad 2. An early version.
